# Thaarei Fleet

Private, independently owned Thaarei Fleet application. Resolved profiles: web, api, data, identity, tenancy, jobs, events, cache, rate-limit.

## Start here

Read docs/developer-guide.md, copy .env.example to .env, then run pnpm install --frozen-lockfile and pnpm dev. Data-enabled projects also run pnpm db:up and pnpm db:migrate.
