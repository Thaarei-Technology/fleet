# Client handover checklist

- [ ] Repository, package, registry, provider, domain, and deployment access transferred through approved channels.
- [ ] Selected profiles, experimental/beta restrictions, exact starter version, and recipe hash reviewed.
- [ ] Environment variable names, rotation owners, backup location, restore exercise, and monitoring destinations reviewed without exposing values.
- [ ] Deployment, migration, rollback, incident, and release-evidence procedures demonstrated.
- [ ] Open work items, waivers, expirations, external qualification gaps, and commercial/legal decisions acknowledged.
