# First-release ownership checklist

- [ ] Configure real GitHub team/user ownership and branch protection; do not infer CODEOWNERS from free text.
- [ ] Configure private package read access and protected deployment environments.
- [ ] Replace local origins, secrets, provider accounts, domains, and sender identities.
- [ ] Set product-specific SLO, capacity, RPO, RTO, residency, and data-classification decisions outside starter defaults.
- [ ] Complete exact-target deployment, rollback, monitoring, backup, and restore qualification.
- [ ] Confirm Nishanth owns engineering admission and Nishanth owns operational admission.
